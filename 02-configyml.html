config.yml resource types

Cheat sheet · 02

Top-level keys that declare the lab's infrastructure. Order does not matter.

version: "3" # quote the value — unquoted 3 breaks the parser
containers

Docker containers. Lightest, fastest. Most tracks start here.

- name: workstation image: gcr.io/instruqt/cloud-client ports: [8080] memory: 1024 shell: /bin/bash environment: KEY: value
Gotcha: port not in ports: cannot be reached from a service tab.
virtualmachines

Full Linux VM. Required for display server, kernel work, custom images.

- name: app image: ubuntu-os-cloud/ubuntu-2204-lts memory: 4096 cpus: 2 allow_external_ingress: [http, https, high-ports] nested_virtualization: false provision_ssl_certificate: true
Gotcha: fail-message and set-status do not exist on VMs (exit 127).
virtualbrowsers

Browser tabs pointing at URLs. Pair with a browser-type tab.

- name: app-portal url: https://app.${_SANDBOX_ID}.instruqt.io/
Use when: exposing a cloud console or sandbox-aware URL through a browser tab.
aws_accounts

Provisioned AWS account with IAM. Two identities (user + admin).

- name: lab services: [s3, ec2, iam] regions: [us-east-1] managed_policies: [arn:...] admin_managed_policies: [arn:...] iam_policy: | # inline JSON {...}
Gotcha: service not in services: errors at runtime.
azure_subscriptions

Provisioned Azure subscription. RBAC roles for user and admin.

- name: lab services: [Microsoft.Compute] regions: [eastus] roles: [Reader] admin_roles: [Owner]
Tip: credentials available via /etc/profile.d/instruqt-env.sh.
gcp_projects

Provisioned GCP project. User and admin service account keys.

- name: lab services: - compute.googleapis.com regions: [us-central1] roles: [roles/compute.viewer] admin_roles: [roles/owner]
Pattern: use CLOUDSDK_AUTH_CREDENTIAL_FILE_OVERRIDE for one-shot admin operations.
secrets

Named values whose actual values live in the platform UI.

- name: VENDOR_API_KEY - name: ARANGO_PWD
Use for: credentials, API tokens, license keys. Available as ${NAME} in containers/VMs.

Across all resource types

  • Resource name doubles as the hostname AND the lifecycle script suffix (e.g. setup-workstation runs on the resource named workstation).
  • Container names should avoid underscores — they double as DNS labels.
  • Auto-injected INSTRUQT_* variables (per cloud account) are added to every host's environment without being declared.
  • Use sandbox_preset in track.yml instead of config.yml when a vendor-supplied preset covers the track's needs.
