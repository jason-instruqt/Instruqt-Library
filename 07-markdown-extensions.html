Markdown extensions

Cheat sheet · 07

Instruqt-specific syntax for the assignment.md body — beyond standard Markdown and the code block modifiers (Sheet 06).

Tab buttons

Inline links that switch the active tab.

[button label="Terminal 1" background="#444CE7" color="#FFFFFF"](tab-0)

tab-N is zero-based; matches the order of the tabs: array in frontmatter. background and color are optional.

Variable interpolation

Render values set via agent variable set.

[[ Instruqt-Var key="DB_ENDPOINT" hostname="workstation" ]]

Resolved at render time. Use for dynamic values: provisioned IPs, generated passwords, region names. Pair with agent variable set in a setup script.

Admonitions

GitHub-style callouts for emphasis. Visual styling is automatic.

> [!NOTE] Helpful context
> [!WARNING] Be careful
> [!IMPORTANT] Drives next step
> [!TIP] Shortcut / pro tip
> [!NOTE] > The check script accepts both 'enriched' and 'governed' as > valid terminal states.

Use sparingly. Admonitions on every step make them invisible.

Pre-challenge notes (frontmatter)

Slides shown as a full-screen overlay before the challenge becomes active.

notes: - type: text contents: | In this challenge, you'll configure a permissions model that mirrors production. - type: image url: ./assets/architecture-diagram.png - type: video url: https://example.com/intro.mp4

Critical: set enhanced_loading: false at track level — without it, notes silently degrade to a clickable tab the learner may never open.

Notes

  • Tab buttons reference the order in tabs:, not labels — (tab-0) is always the first tab listed, regardless of its title.
  • Instruqt-Var requires both key and hostname. The hostname must match the host where agent variable set ran.
  • Admonitions render as styled blockquotes — they support inline Markdown (links, code, emphasis) inside the body.
  • Notes only display as overlays when enhanced_loading: false. First challenge typically uses enhanced_loading: null (inherit); later challenges with notes set it to false explicitly.
