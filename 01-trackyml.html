track.yml fields

Cheat sheet · 01

Track-level metadata and UI configuration. Sits at the root of every track directory.

Identity

slugMust match the directory name.
idUUID. Omit on first push; never modify after assignment.
titleTrack title shown to learners.
teaserOne-line summary for lists.
descriptionLong-form description (Markdown).
iconRelative path or HTTPS URL.
levelbasic / intermediate / advanced.
tagsArray of category strings.
checksumAuto-generated. Do not edit.

Pacing & loading

timelimitTotal seconds. Track-level clock.
idle_timeoutSeconds before idle teardown.
show_timerWhether learner sees the clock.
skipping_enabledWhether learner can skip a challenge.
pausableWhether the lab can be paused.
pausable_ttlMax pause duration in seconds.
enhanced_loadingSet to false when using notes overlays.
extend_ttlAllow learner-initiated time extension.

lab_config — layout

theme.nameoriginal / modern-dark.
default_layoutAssignmentLeft / AssignmentRight.
default_layout_sidebar_sizeAssignment panel width (typically 30–40%).
override_challenge_layoutAllow per-challenge overrides.
sidebar_enabledShow or hide the sidebar.

lab_config — UI

loadingMessagesArray of 2–4 short strings shown during boot.
hideStopButtonRemove the lab stop button.
feedback_recap_enabledPost-track feedback recap.
feedback_tab_enabledPersistent feedback tab.

Notes

  • id is permanent — modifying after assignment creates a new platform record and disconnects local files. Omit when adding new tracks; let the platform assign.
  • For tracks using notes: slides, set enhanced_loading: false at track level. Without it, notes degrade silently into a clickable tab.
  • sandbox_preset (top-level) is an alternative to config.yml — when present, no infrastructure file is needed.
  • Per-challenge lab_config in assignment.md frontmatter overrides track-level defaults when override_challenge_layout: true.
